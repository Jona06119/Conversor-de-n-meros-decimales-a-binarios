# Conversor de Decimal a Binario

## Descripción

Este proyecto consiste en un programa desarrollado en lenguaje C que convierte números decimales enteros a números binarios.

El programa utiliza divisiones sucesivas entre 2 para obtener los residuos y construir la representación binaria del número ingresado.

## Características

* Conversión de números decimales enteros a binarios.
* Validación de la entrada del usuario.
* Manejo del número cero.
* Uso de estructuras de control y arreglos.
* Interfaz sencilla mediante la terminal.

## Tecnologías utilizadas

* Lenguaje C.
* GCC.
* Visual Studio Code.

## Requisitos

* Tener instalado un compilador de C, como GCC.
* Contar con una terminal para ejecutar el programa.

## Instalación y ejecución

1. Clona este repositorio o descarga el archivo `Decimal a Binario.c`.

2. Abre una terminal en la carpeta del proyecto.

3. Compila el programa:

   ```bash
   gcc Decimal a Binario.c -o Decimal a Binario.exe
   ```

4. Ejecuta el programa:

   En Windows PowerShell:

   ```powershell
   .\Decimal a Binario.exe
   ```

## Ejemplo de ejecución

```text
====================================
   CONVERSOR DECIMAL A BINARIO
====================================
Ingresa un numero decimal entero: 25
El numero binario es: 11001
```
